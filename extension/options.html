FOURDOCK · PROTOTYPE

Your workspace

Four services. A separate browser profile. Your browser handles authentication and notifications.

Keep services running

Use the sidebar's down arrow or Fourdock → Hide Workspace. Closing the Chrome window closes its tabs and can discard unsaved drafts. Cmd+Q in Fourdock quits the dedicated browser. Browser menu commands belong to Chrome.

Notifications

Enable notifications inside each service, allow its browser prompt, then allow Google Chrome in macOS System Settings → Notifications. Fourdock never requests microphone or camera access. Calls are outside this prototype's scope.

Service diagnostics

This snapshot contains service identifiers, counts and preferences. No page titles, URLs, account names, messages, cookies or credentials.



Authentication checks
WhatsApp QR plus the actual passkey and corporate Gmail SSO/MFA still require your verification. No login is marked passed automatically. Use only the official service interfaces for credentials.
